# Wordloom

Make words yours. Wordloom helps you collect unfamiliar English words, practice them with active recall, and review them again over time.

**Live app:** https://wordloom-wfoe.onrender.com

## What it does

- Look up up to ten words at a time or add your own definitions.
- Practice with flashcards, matching quizzes, cloze prompts, and sentence writing.
- Pick vocabulary from pasted reading material.
- Track due reviews, activity, and difficult words.
- Keep guest words in this browser, or create an account to sync a collection across devices.
- Export and import JSON backups.

## Run locally

Requires Node.js 22.13 or newer.

```sh
npm ci
npm start
```

Open http://127.0.0.1:4173. Guest mode works without server settings. To enable account APIs, configure `DATABASE_URL`, `APP_ORIGIN`, and `PASSWORD_PEPPER`; set `DATABASE_CA` to your provider's CA certificate when required. The server reads environment variables directly; use Node's `--env-file` option to load a local env file.

## Accounts and saving

Users can create accounts with a username and password, and add an email address or phone number for password resets. Passkeys are optional. Password-reset links expire after 30 minutes and can only be used once. Configure `RESEND_API_KEY` and `EMAIL_FROM` for email delivery, and/or `TWILIO_ACCOUNT_SID`, `TWILIO_AUTH_TOKEN`, and `TWILIO_FROM_NUMBER` for text delivery. Until a delivery channel is configured, its reset option clearly reports that setup is incomplete. Contact details are not verified at signup; users should enter a contact they control. Passwords are stored as salted PBKDF2-SHA-256 verifiers protected by a server secret. Fingerprints, facial data, private passkey keys, and device PINs are not sent to Wordloom.

The Practice Studio can suggest vocabulary by topic through Datamuse. Wordloom then looks up selected definitions using the Free Dictionary API, just as it does for manually entered words. Datamuse documents its word-finding API as read-only and currently keyless; the service says API keys will be required starting January 1, 2027. Vocabulary.com does not offer a public API for this use, and its terms restrict systematic retrieval of content.

Sessions expire after 14 days and use `Secure`, `HttpOnly`, `SameSite=Lax` cookies. Session and recovery tokens are stored as hashes. Sign-in challenges are single-use, expire after five minutes, and verify the configured origin and RP ID. Writes require a same-origin request and are rate-limited. Account collections allow up to 5,000 words and 20,000 reviews per user, with a 2 MB request limit. Device backups are ordinary browser storage, so export them regularly.

Offline changes retry while the page is open. When concurrent changes conflict, Wordloom asks the user to choose which version to keep instead of silently merging them. Guest storage remains separate from account storage; users can import guest words after signing in.

## Hosting on Render

`render.yaml` defines a free Node web service, now live at the link above. Render does not offer managed MySQL, so Wordloom needs a separate MySQL provider. Aiven offers a free tier with 1 GB storage and no credit card, but its service has limited capacity and can be stopped after extended inactivity. Render's free web services sleep after 15 minutes without traffic. See [Render's free-instance limits](https://render.com/docs/free) and [Aiven's free MySQL limits](https://aiven.io/docs/products/mysql/concepts/mysql-free-tier).

When connecting this repository to Render, provide:

- `APP_ORIGIN`: the exact public HTTPS origin, without a trailing slash.
- `DATABASE_URL`: the provider's `mysql://` connection string.
- `DATABASE_CA`: the provider's CA certificate, required for Aiven certificate verification.
- `PASSWORD_PEPPER`: generated by Render's Blueprint.

Wordloom creates its MySQL tables on first connection. Until the database credentials are added, the deployed app runs in guest mode and account sign-in is unavailable. Passkeys are tied to the app's hostname; changing it later requires planning an account migration.

## Optional AI feedback

The server can provide vocabulary feedback for a learner's sentence. Configure `OPENAI_API_KEY` and optionally `OPENAI_MODEL` (default `gpt-4.1-mini`). The UI asks before sending the word, definition, and sentence to OpenAI. Requests set `store: false`, limit input and output size, and have a timeout. Add an API spending limit before enabling this publicly. AI feedback can be wrong, so review it critically.

## Data and sources

Guest collections stay in browser storage; signed-in collections and review history are saved in MySQL. Word lookups send only the requested words to the Free Dictionary API. Starter definitions and examples are original learning copy. Browser speech synthesis may use device or browser voice services.
